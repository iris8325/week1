# IIT Week 1

Repo: https://github.com/iris8325/week1

This is the same small program written three times, once in each language. Each
one prints Hello! and then prints the word infrastructure backwards.

Python and JavaScript were the quickest to get running. I just typed
python3 hello.py and node hello.js and the answer appeared straight away.

C took the longest. I had to compile it first with gcc hello.c -o hello, which
built a new file called hello, and only then could I run ./hello. Two steps
instead of one.

That is the compiled vs interpreted difference from the lecture. Python and
JavaScript are interpreted, so the interpreter runs my file as it reads it. C is
compiled, so the whole file gets turned into a program before anything can run.
More setup, but I suppose that is the price for the computer knowing exactly
what to do and me being able to control it more closely.
